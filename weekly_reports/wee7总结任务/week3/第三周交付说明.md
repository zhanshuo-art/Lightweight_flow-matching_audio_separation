# 第三周交付说明

## 1. 本周目标

Week 3 的目标是完成一个可训练、可评估、可复现的基础音源分离 baseline，并为 Week 4 的底层算子替换留下稳定接口。

最终交付：

```text
ESC-50 2-mix waveform
-> log-magnitude STFT
-> mixture-to-target Flow Matching
-> self-attention Mini-DiT
-> 1-step inference
```

## 3. 关键修正

原先沿用了 `100 steps` 采样，后来验证发现对当前线性 `mixture -> target` flow 不合适。

正式协议改为：

```text
1 step inference
```

同一个 magnitude checkpoint 在验证集上：

| 推理步数 | SI-SDR |
|---|---:|
| `100` | `-1.123 dB` |
| `1` | `-0.439 dB` |

这是本周最重要的工程性修正之一。

## 4. 复数频谱实验

我们还完成了：

```text
week3/configs/minidit_complex_self_attention.yaml
week3/runs/minidit_complex_self_attention/
```

该版本直接使用 real / imag 双通道复数谱，并完成了云端训练、验证和测试。

测试集 `1 step` 结果：

| 模型 | waveform L1 | SI-SDR |
|---|---:|---:|
| magnitude baseline | `0.03203` | `-0.419 dB` |
| complex experiment | `0.03665` | `-0.937 dB` |

因此它当前不替代正式 baseline，而是作为一个清楚的实验结论保留：复数信息更完整，但若损失函数和一致性约束不跟着调整，并不会自动带来更好结果。
