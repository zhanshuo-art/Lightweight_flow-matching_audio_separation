# Week 3：特征、训练目标与输出解释

## 1. 正式主线

Week 3 最终采用：

```text
waveform
-> log-magnitude STFT
-> self-attention Mini-DiT
-> magnitude prediction
-> mixture phase + iSTFT
```

这是当前实验里表现最稳的 baseline。复数谱版本也已经实现并评估，但暂时作为扩展实验保留。

## 2. 输入数据

| 项目 | 说明 |
|---|---|
| 原始数据 | Week 2 生成的 ESC-50 2-mix waveform |
| 音频格式 | 16 kHz, mono, 5 秒 |
| 单条样本 | `mixture waveform`, `target waveform`, `target_label` |

## 3. 正式特征构造

对波形做：

```text
STFT(n_fft=1024, hop_length=256, win_length=1024)
```

再取：

```text
log1p(|STFT|)
```

得到：

```text
[1, 513, 313]
```

其中：

- `513` 是频率 bin 数；
- `313` 是时间帧数；
- `1` 是单通道幅度谱。

## 4. 训练目标

对 mixture 特征 `x0` 和 target 特征 `x1`：

```text
t ~ Uniform(0, 1)
xt = (1 - t) * x0 + t * x1
v* = x1 - x0
v_pred = model(xt, t, mixture_feature, label)
x1_pred = xt + (1 - t) * v_pred
loss = L1(v_pred, v*) + L1(x1_pred, x1)
```

两部分含义：

1. `velocity loss`：模型要学会从 mixture 往 target 走的方向；
2. `endpoint loss`：按该方向走到终点后，结果要接近 target。

## 5. 模型到底输出什么

网络直接输出的是：

```text
1 通道 velocity field
```

推理时从 mixture 特征出发，根据预测速度更新到 target 特征。因为这条 flow 本身是线性的，正式协议使用：

```text
1 step inference
```

而不是把同一个方向反复积分很多次。

## 6. 如何还原成波形

正式 baseline 只预测目标幅度谱，因此重建时使用：

```text
predicted magnitude + mixture phase -> complex STFT -> iSTFT
```

这一步解释了为什么它仍然不是一个“完美的分离器”：它没有自己建模相位，而是借用了 mixture 的相位。

## 7. 为什么还做了复数频谱实验

复数版本使用：

```text
[real(STFT), imag(STFT)]
```

模型直接预测两通道，理论上可以同时承载幅度和相位信息。代码链路已经打通，输出也可直接 iSTFT。

但当前结果显示：

| 模型 | Test waveform L1 | Test SI-SDR |
|---|---:|---:|
| magnitude baseline | `0.03203` | `-0.419 dB` |
| complex experiment | `0.03665` | `-0.937 dB` |

所以，单纯“把通道换成 real / imag”并不足以自动变强。后续若继续做复数频谱，应把 waveform-domain loss、相位一致性或 STFT consistency 纳入设计。

## 8. 当前输出文件

| 输出 | 说明 |
|---|---|
| `metrics.csv` | 训练 / 验证 loss |
| `checkpoints/best.pt` | 最优 checkpoint |
| `summary.json` | 采样或评估摘要 |
| `samples.csv` | 每条样本的评估指标 |

| `by_pair.csv` | 按 source pair 聚合 |

| `mixture.wav`, `target.wav`, `prediction.wav` | 音频输出 |
