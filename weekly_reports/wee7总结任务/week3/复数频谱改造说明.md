# Week 3 复数频谱改造说明

## 1. 为什么做这个实验

旧 baseline 只预测幅度谱，重建时要复用 mixture phase。直觉上，这会限制最终波形质量，所以我们实现了复数频谱版本：

```text
complex STFT
-> real / imag 双通道
-> signed-log compression
-> Mini-DiT
-> direct iSTFT
```

## 2. 已完成的改造

| 文件 | 变化 |
|---|---|
| `audio_features.py` | 增加通用 `STFTFeatureCodec`，支持 magnitude 与 complex 两种表示 |
| `estimate_sigma.py` | 可为复数实部 / 虚部估计统计量 |
| `train_minidit.py` | 支持双通道复数特征训练 |
| `sample_minidit.py` | 复数输出可直接 iSTFT |
| `evaluate_minidit.py` | 支持复数输出评估 |
| `minidit_complex_self_attention.yaml` | 复数实验配置 |

## 4. 一个重要发现：长步数采样会伤害相位

对复数版本，验证集结果为：

| 步数 | SI-SDR |
|---|---:|
| `1` | `-0.976 dB` |
| `5` | `-1.095 dB` |
| `25` | `-1.600 dB` |
| `100` | `-1.978 dB` |

这说明在当前线性 `mixture -> target` flow 中，长链 Euler 积分会不断积累相位误差。这个发现也促使我们把所有正式实验统一改为 `1 step`。

## 5. 为什么复数版这次没有赢

复数谱保留的信息更多，但也更难学。当前训练仍只优化：

```text
feature-domain velocity L1 + endpoint L1
```

它并没有显式约束：

1. 波形重建质量；
2. 复数谱的一致性；
3. 相位误差对时域波形的影响。

所以这次结果说明的不是“复数谱没有价值”，而是：

```text
只把输入从 magnitude 换成 real / imag，不足以构成更强模型。
```

## 6. 后续若继续做复数谱，应该怎么做

建议至少加入其中一类改造：

1. waveform-domain auxiliary loss；
2. phase-sensitive loss；
3. STFT consistency projection；
4. complex mask / residual parameterization；
5. multi-resolution STFT loss。

这些已经超出干净 Week 3 baseline 的范围，更适合作为后续加强版实验，而不是在 Week 4 结构对比前先把地基搅乱。
